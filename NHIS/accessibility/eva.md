# EVA human factors

NASTRA EVA is not described as WCAG compliant. A visor is not web content. EVA reuses accessibility principles only where they help human performance.

- Redundant coding: every alert class reads in monochrome by shape, outline, position, size and flashing (B5).
- Two channels: every Caution, Warning and Emergency raises an annunciation event for sound (B4). Nothing depends on vision alone.
- Two modalities: every function works by voice and by the wrist control (B29).
- Legibility: text set in visual angle, medium or bold, white or green (B20 to B22).
- Error prevention: state-changing voice commands are read back; gaze never commits (B30, B31).
- Motion: no ambient or oscillating motion; flashing stops on acknowledgement (B27, B28).

Everything here is a starting value awaiting suited or analog tests (`validation/unresolved-decisions.md` U-05 to U-07, U-16, U-17, U-19).
